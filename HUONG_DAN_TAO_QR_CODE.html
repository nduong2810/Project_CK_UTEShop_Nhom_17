📱 Hướng dẫn Tạo QR Code cho Thanh toán

⚠️ LƯU Ý QUAN TRỌNG: Sau khi hoàn thành các bước dưới đây, tính năng thanh toán bằng QR Code sẽ hoạt động hoàn chỉnh!

🎯 Các bước thực hiện

Bước 1: Tạo QR Code trực tuyến

Truy cập các trang web sau để tạo QR Code:

🏦 Cho Chuyển khoản Ngân hàng:
https://qr.sepay.vn/ (Miễn phí, hỗ trợ VietQR)
💳 Cho Ví MoMo:
Vào app MoMo → Mã QR → Lưu hình

Thông tin cần có:

  • Tên ngân hàng / Số điện thoại MoMo
  • Số tài khoản / Số điện thoại
  • Tên chủ tài khoản
  • Số tiền (có thể để trống)
  • Nội dung chuyển khoản

Bước 2: Lưu QR Code vào thư mục

Sau khi tạo QR Code, lưu file ảnh với tên theo format:

Cửa hàng QR Bank QR MoMo
TechZone (maCH=1) techzone_bank_qr.png techzone_momo_qr.png
FashionHub (maCH=2) fashionhub_bank_qr.png fashionhub_momo_qr.png
HomeDecor (maCH=3) homedecor_bank_qr.png homedecor_momo_qr.png

📁 Đường dẫn lưu file:

src/main/webapp/assets/img/qr/

✅ Thư mục đã được tạo sẵn!

Bước 3: Cập nhật Database

Mở file update_payment_qr.sql và chạy script trong MySQL/HeidiSQL:

  1. Mở HeidiSQL hoặc MySQL Workbench
  2. Kết nối đến database uteshop
  3. Copy nội dung file SQL và Execute
  4. Kiểm tra kết quả bằng query cuối cùng trong file
📌 Lưu ý: Bạn cần điều chỉnh thông tin trong file SQL cho đúng với thông tin thực tế của bạn (số tài khoản, tên chủ tài khoản, v.v.)

Bước 4: Khởi động lại Server và Test

  1. Khởi động lại Tomcat server
  2. Truy cập trang checkout
  3. Chọn phương thức thanh toán "Chuyển khoản Ngân hàng" hoặc "Ví MoMo"
  4. Nhấn "Tôi xác nhận" → Modal QR sẽ hiển thị

🔧 Khắc phục sự cố

❌ Nếu QR Code không hiển thị:

  • Kiểm tra đường dẫn file: File ảnh phải nằm trong src/main/webapp/assets/img/qr/
  • Kiểm tra tên file: Tên file trong database phải khớp với tên file thực tế
  • Kiểm tra định dạng: Hỗ trợ .png, .jpg, .jpeg
  • Xóa cache trình duyệt: Ctrl + Shift + Delete
  • Kiểm tra console: F12 → Console để xem lỗi

📝 Tóm tắt các file đã được cập nhật

  • ✅ checkout.jsp - Đã thêm modal xác nhận và hiển thị QR
  • ✅ assets/img/qr/ - Thư mục lưu QR Code đã được tạo
  • ✅ update_payment_qr.sql - Script cập nhật database
  • ✅ JavaScript - Xử lý lỗi khi không có QR Code

🎨 Tạo QR Code mẫu nhanh (Không cần tài khoản thật)

Nếu bạn chỉ muốn test giao diện, có thể dùng QR Code generator online:

https://www.qr-code-generator.com/
Tạo QR Code bất kỳ với nội dung text hoặc URL

Sau đó lưu ảnh và đặt tên theo bảng ở Bước 2.

🎉 KẾT QUẢ MONG ĐỢI:
Sau khi hoàn thành, khi khách hàng chọn thanh toán Bank/MoMo:
  1. Modal xác nhận hiển thị
  2. Nhấn "Tôi xác nhận" → Modal QR hiển thị với đầy đủ thông tin
  3. Hiển thị QR Code, thông tin tài khoản, nút copy
  4. Nhấn "Tôi đã thanh toán" → Có thể đặt hàng
